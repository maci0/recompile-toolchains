# Release readiness: 1.18.0, 2026-11-22

Every recipe fetches by an immutable reference except six awaiting a mirror: the 36 GitHub archives are fetched by the commit `sources.json` records (same trees, new sha256s), `modern-asn64.py` by its commit, `libtinfo5` from snapshot.debian.org. The three base images are pinned by digest and install exact package versions from dated snapshot archives. `make images` checks every fetched sum and every entry's compiler, reads an image built from a branch archive that a commit archive replaced as `ok (branch)` (so the published images keep their ids), fails byte-identical compilers no `same_compiler_as` or `variant_of` ties, and compiles a test source in each local image to fail an object whose machine disagrees with the row's `arch` and `bits` (`WRONG-TARGET`).
